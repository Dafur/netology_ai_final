## Чек-лист проверки

### Проверка основных сценариев

- [ ] корректный запрос → успешный ответ;
- [ ] некорректный ввод → ошибка валидации;
- [ ] сбой внешнего вызова → fallback.

### Проверка инфраструктуры

- [ ] сервис запускается одной командой;
- [ ] CI проходит успешно;
- [ ] конфигурации работают корректно.
